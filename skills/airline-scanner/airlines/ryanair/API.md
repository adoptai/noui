## `get_v4_en_us_availability`

**GET** `https://www.ryanair.com/api/booking/v4/en-us/availability`

Search Ryanair flights for a given route, date, and passenger count. Returns available flights with fares for the requested date range (with flex-day window).

### Authentication

None required. The endpoint is publicly accessible.

### Query Parameters

| Parameter | Type | Required | Default | Description |
|---|---|---|---|---|
| `ADT` | string | yes | — | Number of adult travelers. |
| `TEEN` | string | no | `"0"` | Number of teen travelers. |
| `CHD` | string | no | `"0"` | Number of child travelers. |
| `INF` | string | no | `"0"` | Number of infant travelers. |
| `Origin` | string | yes | — | Origin IATA airport code (e.g. `DUB`). |
| `Destination` | string | yes | — | Destination IATA airport code (e.g. `STN`). |
| `DateOut` | string | yes | — | Outbound date in `YYYY-MM-DD` format. |
| `DateIn` | string | no | `""` | Return date in `YYYY-MM-DD` format (round-trip only). |
| `RoundTrip` | string | no | `"false"` | `"true"` for round-trip search. |
| `promoCode` | string | no | `""` | Promotional code. |
| `IncludeConnectingFlights` | string | no | `"false"` | Include connecting flights. |
| `DestinationIsMac` | string | no | `"false"` | Whether destination is a MAC code. |
| `FlexDaysBeforeOut` | string | no | `"2"` | Flex days before outbound date. |
| `FlexDaysOut` | string | no | `"2"` | Flex days after outbound date. |
| `FlexDaysBeforeIn` | string | no | `"2"` | Flex days before return date. |
| `FlexDaysIn` | string | no | `"2"` | Flex days after return date. |
| `IncludePrimeFares` | string | no | `"false"` | Include prime fares. |
| `ToUs` | string | no | `"AGREED"` | Terms of use agreement flag. |
